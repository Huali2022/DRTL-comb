# DRTL-comb
A transfer learning framework for missing binary covariates
## Usage
You first need to install R packages "BB" and "MASS", and load "functions_binary.R". We describe the data generation and how to conduct the proposed method for given dataset in "main_binary.R". After running the "main_binary.R", you can obtain the point estimator, variance estimator of the proposed method.
